# Painel do Mestre — A Maldição do Ídolo de Pedra

Primeira versão navegável de um painel estático para apoiar a condução do playtest.

## Executar
Abra `index.html` em um navegador moderno ou publique a raiz com GitHub Pages. Não há backend, conta ou instalação.

## Publicar
Em **Settings → Pages → Deploy from a branch**, selecione `main` e `/(root)`. `develop` é a branch de desenvolvimento; integre-a em `main` somente depois de testar.

## Dados
O progresso é salvo no `localStorage` deste navegador e não sincroniza entre dispositivos. Use **Dados e backup** para exportar/importar JSON.

## Fidelidade ao playtest
Esta é uma primeira versão funcional, não uma transcrição integral. As notas são resumos operacionais; consulte o PDF oficial para descrições completas, regras, DTs e exceções. Não inclua o PDF oficial neste repositório público.
